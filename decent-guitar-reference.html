🎸 Decent Guitar

Project Reference — last updated July 2026

Overview

Decent Guitar is a personal web app for supporting acoustic guitar learning. It provides a song library with chord-annotated scrolling lyrics (similar to Ultimate Guitar's chord view), a chord fingering library with SVG diagram rendering, strumming pattern reference, fingering exercises with tab notation, and a full Practice module covering chord cycling, strumming drills, song practice, finger exercises, and timing.

Deployment Workflow

  1. Download updated index.html from Claude
  2. Go to github.com/danielgomez909/decent-guitar
  3. Open the file → click pencil (edit) icon → select all, paste new content
  4. Commit changes — Vercel auto-deploys in ~30 seconds
  5. Verify at the Vercel URL

Note: decent-guitar-reference.html is no longer deployed separately — reference content is inlined in the Reference tab of the app.

Assigns a song-specific ordered sequence to part instances. Unique on (song_id, part_order). Allows the same part (e.g. Verse) to appear multiple times in one song at different positions.

Overrides the song-level default strumming pattern for a specific part instance. Shown as a badge next to the part label in the song detail view.

song_lyrics

One row per line. Lines are strictly ordered by line_order within a part. Three line types: chord lines (green, fixed-width, align above lyrics), lyric lines (white, fixed-width Courier), comment lines (italic, muted, Lora serif — for notes/annotations).

line_orderint1-based. Unique with song_parts_order_id.

line_typetextCheck: 'chords', 'lyrics', 'comment'

fingering_exercises

Admin-managed tab exercises displayed in Practice → Fingering. Tab is stored as jsonb with one key per string (e, B, G, D, A, E), each containing a space-separated sequence of fret numbers, 'x' for rest, or blank if the string is unused.

Practice Module

SubtabDescription
Chord CyclingTap chips to build chord sequence. BPM, Beats per Chord, Start Delay (1–20s). 10s countdown shows first chord before clicks start. Audible metronome (high pitch on beat 1), live fingering table, next-chord preview.
Strumming DrillTap to select pattern. BPM, Start Delay (1–20s), Repeat Count (default 10). Large slot display highlights active stroke. D=orange, U=green, rest=muted dot. Distinct tones per stroke type. Auto-stops after N cycles.
Practice SongLink-out to Songs tab.
FingeringSpider Walk reminder + list of admin-managed tab exercises. Tap exercise to view tab notation display.
TimingStandalone metronome. BPM, Duration (5s increments to 120s), Start Delay (1–20s). Pendulum-style alternating dot visual, MM:SS countdown, auto-stops.

Chord Diagram Renderer

SVG-based, generated from the fingering jsonb. String order: e (top) to high_e (bottom) in display; rendered left-to-right as e, a, d, g, b, high_e. Features: thick nut bar for open-position chords, fret position label for higher chords, X (SVG lines) for muted strings, O (SVG circle) for open strings, filled orange dots for fretted notes. Finger numbers displayed below the diagram. Toggle button in modal to switch between diagram and string table view. Mini diagrams shown on chord cards in the Chords tab grid.

Tab Notation (Fingering Exercises)

Standard guitar tab format: 6 horizontal lines, top = high e, bottom = low E. Each column is 3 characters wide for alignment. Fret numbers left-justified, padded with dashes. 'x' = rest/mute, blank string = not played. Entered in Admin as space-separated tokens per string (e.g. 5 3 1 3 5 5 5 x 3 3 3 x 5 5 8).

UG Text Import

Admin → Songs → paste UG-style text → Parse Text. Extracts title/artist, capo, splits on [Part] markers, classifies chord vs lyric lines, matches part names to the parts table. Populates the parts builder UI for review before saving. Clear button resets the textarea for back-to-back imports.

Key Technical Notes

  • Auto-scroll uses requestAnimationFrame (not setInterval) for iPad compatibility
  • Chord modal is at document level (not inside tab-chords div) so it opens from any tab
  • Per-song scroll prefs stored in localStorage as dg_song_prefs_{songId}
  • Supabase join-filter: fetch related IDs first, then use in.(...) filter
  • Song save is a full rewrite of nested structure (delete cascade + reinsert)
  • Reference content is inlined in the app's Reference tab — decent-guitar-reference.html is kept in the repo but not used by the app
